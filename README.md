
# StudySprint 🎯

### Your Personal Study Planner & Student Productivity Dashboard

StudySprint is a responsive, browser-based productivity application designed to help students organize academic tasks, plan study sessions, track daily goals, and monitor their learning progress.

🌐 **Live Demo:** https://amardeepkeshri.github.io/StudySprint/

## ✨ Features

- **Task Management** — Create, complete, delete, and filter academic tasks.
- **Smart Study Planner** — Get rule-based suggestions for organizing your study workload.
- **Calendar & Exam Planner** — Organize deadlines and exam dates.
- **Focus Room** — Use timed study sessions and breaks.
- **Daily Goals & Streaks** — Track study targets and consistency.
- **Subject Analytics** — Review progress across subjects.
- **Weekly Progress** — Visualize your task-completion history.
- **XP & Rewards** — Earn experience points for your progress.
- **Study Assistant** — Get basic study guidance using built-in rules.
- **Profile & Settings** — Personalize your profile and appearance.
- **Data Backup** — Export and import supported JSON backups.

## 🚀 Getting Started

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/amardeepkeshri/StudySprint.git
   ```

2. Open the project folder:

   ```bash
   cd StudySprint
   ```

3. Open `index.html` in your browser, or open the folder in VS Code and run it using the Live Server extension.

No build tools or API keys are required for the current version.

## 💾 Data Storage

StudySprint stores supported tasks, settings, and progress data in the browser's local storage.

- Data generally remains available in the same browser on the same device.
- Browser data clearing can remove locally stored progress.
- Data does not automatically synchronize between devices.
- Use the backup feature to export and restore supported data.
